# Act2See — project page

Static page for **Act2See: Structured Articulated Representations through Robot Interaction** (RSS 2026).

## Files
- `index.html` — the page. Open it in a browser to preview.
- `assets/` — put your media here (see below).

## Add your media
Open `index.html` and find the commented sections. For each: drop the file
into `assets/`, delete the placeholder `<div>`, and uncomment the real tag.

| What          | File to add                              |
|---------------|------------------------------------------|
| Teaser video  | `assets/teaser.mp4` (+ `teaser-poster.jpg`) |
| Method diagram| `assets/method.png`                      |
| Result clips  | `assets/exp-cabinet.gif`, `exp-drawer.gif`, `exp-laptop.gif` |

## Publish to GitHub Pages
1. Create a new **public** repo (e.g. `act2see`).
2. Commit `index.html` and the `assets/` folder to the repo root.
3. Repo → **Settings → Pages** → Source: **Deploy from a branch** →
   Branch `main` + `/ (root)` → Save.
4. Live in ~1 min at `https://lauyihong.github.io/act2see/`.
